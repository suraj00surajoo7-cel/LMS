Career in Cyber Security

A defensive security roadmap covering networks, operating systems, security concepts, cryptography, tools, SOC work, and incident response.

4career phasesSOCanalyst-ready focus
Months 1-3

Networking & Systems

  • OSI model, TCP/IP, DNS, HTTP/S, subnetting, firewalls, VPNs, and packet flow.
  • Linux and Windows administration, users, permissions, services, logs, and hardening basics.
  • Practice Wireshark packet analysis and write short findings reports.
Months 4-8

Security Fundamentals

  • CIA triad, authentication, access control, risk management, threat modelling, and cryptography.
  • OWASP Top 10, secure configuration, vulnerability lifecycle, and basic compliance awareness.
  • Certification direction: CompTIA Security+ or equivalent beginner security credential.
Months 9-14

Tools & Detection

  • Nmap, Wireshark, Burp Suite basics, vulnerability scanning, and safe lab validation.
  • SIEM concepts, Splunk or ELK dashboards, alert triage, log correlation, and threat intel basics.
  • Project: home SOC lab with logs, alerts, and an incident write-up.
Months 15-20

Incident Response & Career

  • Incident lifecycle, forensics basics, malware indicators, containment, eradication, and recovery.
  • Build a portfolio with case studies, detection rules, lab notes, and security reports.
  • Apply for Cybersecurity Analyst, SOC Analyst, Security Engineer, and Incident Responder roles.
