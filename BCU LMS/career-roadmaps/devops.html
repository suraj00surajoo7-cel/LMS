Career in DevOps

A hands-on path for learning Linux, networking, Git, containers, CI/CD, infrastructure as code, cloud platforms, and reliability engineering.

4practice phases3must-build projects
Months 1-3

Linux, Networking & Git

  • Linux CLI, permissions, processes, logs, cron, shell scripting, and package managers.
  • Networking fundamentals: TCP/IP, DNS, HTTP/S, SSH, firewalls, ports, and load balancing.
  • Git, GitHub workflows, branching, pull requests, and release notes.
Months 4-7

Containers & CI/CD

  • Docker images, volumes, networks, Docker Compose, and container security basics.
  • Jenkins or GitHub Actions pipelines for build, test, lint, package, and deploy steps.
  • Project: containerize a Flask or Node app and deploy it with a working pipeline.
Months 8-12

Cloud & Infrastructure as Code

  • AWS, Azure, or GCP basics: compute, storage, networking, IAM, monitoring, and billing.
  • Terraform for infrastructure as code and Ansible for configuration management.
  • Project: provision a VM, database, storage bucket, and deployed app using IaC.
Months 13-18

Kubernetes, Monitoring & SRE

  • Kubernetes pods, deployments, services, ingress, config maps, secrets, and Helm basics.
  • Prometheus, Grafana, ELK, alerts, uptime checks, incident response, and runbooks.
  • Project: deploy a microservice app on Kubernetes with dashboards and alerts.
