Career in Ethical Hacking

A responsible offensive-security roadmap for learning networking, Linux, web technology, vulnerability assessment, penetration testing, reporting, and red-team practice.

5practice phasesLabonly ethical practice
Months 1-3

Core Foundations

  • Networking, Linux, Windows basics, web architecture, HTTP, DNS, authentication, and databases.
  • Python and Bash scripting for automation, parsing, and small security utilities.
  • Build a legal local lab using intentionally vulnerable machines and private test apps.
Months 4-7

Web Security

  • OWASP Top 10, SQL injection, XSS, CSRF, SSRF, access control, file upload risks, and authentication flaws.
  • Burp Suite, browser dev tools, recon notes, payload testing, and safe validation.
  • Practice PortSwigger Web Security Academy labs and write clean vulnerability reports.
Months 8-12

Vulnerability Assessment

  • Nmap scanning, service enumeration, CVE research, Nessus/OpenVAS basics, and risk scoring.
  • Metasploit in a controlled lab, password attack concepts, privilege escalation basics, and remediation advice.
  • Project: assessment report for a vulnerable lab network with fixes and executive summary.
Months 13-17

Penetration Testing

  • Testing methodology, scope, rules of engagement, evidence capture, impact explanation, and retesting.
  • TryHackMe, Hack The Box, and CTF practice focused on learning, notes, and report quality.
  • Prepare for eJPT, PNPT, CEH, or OSCP depending on your target depth.
Months 18-22

Red Team Career Prep

  • Active Directory basics, phishing awareness for defense, lateral movement concepts, and blue-team collaboration.
  • Build a portfolio with lab reports, write-ups, scripts, and responsible disclosure templates.
  • Apply for Ethical Hacker, Penetration Tester, Red Team Engineer, or Security Consultant roles.
Use this roadmap only for authorized labs, owned systems, or written-permission testing.
